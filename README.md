# GSL Elevation Simulator

Static interactive Great Salt Lake elevation simulator.

## Run Locally

Open `index.html` in a browser. It redirects to `gsl-simulator-v14.1.html`, which contains the current simulator. `gsl-simulator-v14.html` is preserved as the v14 review baseline.

The simulator loads Chart.js and the Chart.js annotation plugin from jsDelivr.
