# v14.1 Implementation Plan

This plan translates the review comments and white-paper updates into a narrow implementation pass.

## Goal

Make v14.1 a hardening release: stronger scientific guardrails, clearer data vintage, editable annual accounting, consistent 2036 horizon, and safer treatment of long-range PDO opportunity graphics.

## Step 1: Preserve v14 and Create v14.1

- Copy `gsl-simulator-v14.html` to `gsl-simulator-v14.1.html`.
- Update `index.html` only after v14.1 is verified.
- Keep v14 untouched as the review baseline.

## Step 2: Update Citation and Maintenance Notes

- Add Codex to the front citation/AI-assistance block.
- Preserve Ian-only authorship.
- Embed a short "maintenance guardrails" comment near the forecast constants in the HTML, while keeping the full guide in `AI-MAINTENANCE-GUIDE.md`.
- Link or reference `AI-MAINTENANCE-GUIDE.md` in the repo documentation.

## Step 3: Add Data Vintage Panel

Add a visible panel showing:

- USGS Saltair value and timestamp.
- CPC ENSO discussion issue date.
- CPC strength probability issue month.
- NCEI PDO latest complete month.
- Whether live or fallback values are being used.

Do not imply that cached current-data text is live unless the fetch succeeds.

## Step 4: Extend Forecast Horizon to 2036

- Extend `FCST_YEARS`, `BASELINE`, `FCST_CI`, annual accounting profiles, Tarboton arrays, and comparison arrays.
- Add separate 2034 milestone and 2036 risk-horizon KPIs.
- Ensure 2036 uncertainty is wider than 2034.
- Update chart titles and report text.

## Step 5: Make Annual Accounting Editable

- Convert annual delivery cells to controlled numeric inputs.
- Track manual overrides by lever/year.
- Recompute forecast immediately after edits.
- Add reset buttons.
- Keep structural baseline gain read-only and separate.

## Step 6: Split Climate Event Logic

- Add a dedicated ENSO/PDO/atmospheric-river scenario function.
- Keep the old ENSO time-constant shortcut only as a compatibility comparison until reviewed.
- Show Stage 1 precipitation opportunity and Stage 2 lake response separately.
- Treat the 2029-2031 bump as a model self-consistency check with uncertain magnitude.

## Step 7: Rework Figures

- Recreate figures from local or official data where data and methods are available.
- Redraw the PDO x ENSO atmospheric-river matrix as provisional unless calibrated coefficients are supplied.
- Recast the 2020-2060 graphic as a conceptual risk/opportunity schematic, not an elevation forecast.
- Use distinct visual cues for observed/current PDO/ENSO windows, forecast-window assumptions, provisional scenario windows, and conceptual long-range regime windows.
- Add atmospheric river to the glossary before using the abbreviation without definition.

## Step 8: Add QA Checks

Verify with two layers:

- Automated/browser-assisted checks in the Codex in-app browser or Playwright-style workflow for deterministic behavior.
- A manual Chrome pass if user-profile behavior, downloads, print/PDF, or real browser rendering needs confirmation.

Minimum checks:

- Overview sliders move graph and KPIs.
- Each Simulator lever changes forecast output.
- Annual edits change the forecast.
- Newfoundland remains non-recurring unless the scenario explicitly includes refill or partial refill, such as a 2026-27 El Nino recharge assumption.
- Structural baseline gain is not double-counted.
- Cross-Validation updates after scenario changes.
- 2036 uncertainty is wider than 2034.
- Preserved tabs render.

## Step 9: Produce Formal Review Documents After Markdown Approval

- Keep Markdown as the working inline-review format for the next review turn.
- After text and figure placement are approved, export to DOCX and PDF.
- Use Times New Roman 12 pt for main body text.
- Fully justify body paragraphs.
- Preserve the current section-header hierarchy.
- Embed figures near first reference with captions.
- Render and visually QA the DOCX/PDF before delivery.

## Deferrals to v15

- Full modular rewrite.
- Live atmospheric-river catalog calibration in browser.
- External build system or database-backed data pipeline.
- Publication-grade scientific calibration without expert review.
